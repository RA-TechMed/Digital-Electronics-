RC Time Constant

The time constant tells you how quickly a capacitor charges or discharges through a resistor.

τ = R × C

Use resistance in ohms and capacitance in microfarads. The calculator converts microfarads to farads automatically.

Enter values to calculate the RC time constant.

555 Timer

The standard astable 555 timer uses the formulas below to calculate period, frequency, duty cycle, and tau.

T = 0.693(RA + 2RB)C F = 1 / T Duty Cycle = (RA + RB) / (RA + 2RB) × 100% τ = RB × C

Calculate from RA, RB, and C

Enter RA, RB, and C to calculate the timer values.
